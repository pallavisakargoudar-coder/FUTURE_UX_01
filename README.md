# 🦷 SmileCare Dental Clinic – Website UI (Task 1)

## 📌 Project Overview

This project is a Local Service Business Website UI designed for a dental clinic named **SmileCare Dental**.

The objective of this task was to design a clean, modern, and user-friendly website interface for a service-based business using proper UI/UX principles.

---

## 🎯 Objective

To design a responsive and structured website UI for a dental clinic that includes:

- Homepage
- Services Page
- Contact Page

The design focuses on clarity, trust-building, and easy appointment booking flow.

---

## 🛠 Tools Used

- Figma (UI Design & Layout)
- HTML5
- CSS3
- Visual Studio Code
- GitHub

---

## 📄 Pages Included

### 🏠 1. Homepage
- Hero section with call-to-action
- Clinic introduction
- Service highlights
- Appointment button
- Clean navigation bar

### 🦷 2. Services Page
- List of dental treatments
- Service cards layout
- Clear headings and descriptions
- Proper visual hierarchy

### 📞 3. Contact Page
- Contact form (Name, Email, Message)
- Clinic contact details
- Clear call-to-action
- Simple and clean layout

---

## 🎨 Design Highlights

- Soft blue color palette for trust and healthcare feel
- Rounded buttons and cards for modern UI
- Proper spacing and alignment
- Clear typography hierarchy
- Mobile-friendly layout structure

---

## 🧠 UX Considerations

- Easy navigation between pages
- Clear primary CTA ("Book Appointment")
- Minimal clutter
- Service-based content structure
- Consistent branding across pages
